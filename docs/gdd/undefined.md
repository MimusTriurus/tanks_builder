# Что не определено в GDD, но решает игру

Список правил, без которых партию по [GDD](index.md) нельзя сыграть или
нельзя сбалансировать. Здесь нет противоречий, только дыры: каждая закрывается
новым абзацем в черновике. Флаг `DoD` описывает минимум, при котором пункт
закрыт. Противоречия вынесены отдельно в [contradictions.md](contradictions.md).

Приоритет: `P0` без этого партия не играется, `P1` без этого нельзя балансить,
`P2` уточнение.

**Ревизия 2026-09-05**, после закрытия C-01…C-09. Что закрытые противоречия
дали этому списку, отмечено в пунктах строкой «Из C-xx». Два пункта, U-16 и
U-17, появились из самих решений: они не были дырами, пока правил не было.

## U-01. Условия победы и конец боя `P0`

Лимита по раундам нет. Пас разрешён (первая запись «запрещён» отозвана, см. ниже).
Записано в раздел «Условия победы».

## U-02. Высота ничего не даёт `P0`

Три уровня, а единственный эффект холма это блок проезда и огня. Не сказано,
стреляет ли танк с холма поверх леса и дыма, видит ли он через них, пробивается
ли сверху. Овраг получил вход и выход (C-03, C-06), но по-прежнему ничего про
стрельбу из него и через него.

**Из C-03 есть прецедент.** У глубокой воды дно на −1, поверхность на 0: пустой
гекс огонь не перекрывает, танк в нём перекрывает как обычный. Это готовая
формула для оврага, если решить, что овраг ведёт себя как вода без воды.

**Решение (2026-09-05).** Прямая наводка бьёт только по своему уровню, миномёт
по любому. Юниты перекрывают огонь только на своём уровне. Через пустой овраг
стрелять можно. Тараном сталкивают на уровень ниже. Глубокая вода стала двух
высот: низкая (−1) и высокая (0), плывущий стоит на уровне своей воды. Записано
в новый раздел «Уровни и линия огня» и разнесено по холму, оврагу, воде, тарану.

**DoD**
- [x] Танк на уровне 1: стреляет и поражается только на уровне 1, с равнины его достаёт лишь миномёт.
- [x] Танк в овраге: перекрывает огонь только на −1, виден только с −1 и миномёту.
- [x] Через пустой овраг стрелять можно.
- [x] Таран сталкивает на уровень ниже без рампы: с холма на равнину, с равнины в овраг или воду. Вверх нельзя.
- [x] Пункт про сведение уровней к скале снят: правила обзора появились.

**Следствия, закрытые автором (2026-09-05):**
- [x] Препятствия на клетках перекрывают огонь только на своём уровне. Два танка на холмах стреляют поверх леса в долине.
- [x] Высокая вода: рампа нужна так же, как для низкой.
- [ ] Оборона на холме: недостижим с равнины ни для кого, кроме HM. **Плейтест.**
- [ ] Столкнутый в овраг без рампы выключен из боя, кроме огня HM. **Плейтест.**

Закрыто: 2026-09-05, GDD «Уровни и линия огня», «глубокая вода». Два пункта ждут плейтеста.

## U-03. Рампа `P0`

Упомянута у холма, оврага и глубокой воды, не описана как клетка. После C-03 и
C-06 на неё опираются три правила: выезд из воды, выезд из оврага и «рампа
спускает» отброшенного тараном. Последнее написано при записи C-06 по аналогии
и означает неизвестно что: рампа это клетка, на которой стоят, или переход, по
которому съезжают.

**Решение (2026-09-05), пересмотрено в U-04.** Первая запись «рампа — свойство
грани» отозвана автором: рампа это **отдельный гекс**, как в коде стенда
(`HexField`: рампа лежит на нижней ступени, принадлежит нижнему уровню, наклонена
к единственному высокому соседу, проезжается только вдоль своей оси). Проезд 2
шага: войти и выйти в одном ходу, потому что остановиться на ней нельзя. Сквозь
пустую рампу стреляют. Вытолкнутый вдоль оси скатывается дальше вниз. Мина на
рампе допустима и запирает подъём подбитым танком. Записано в раздел «Рампа».

**DoD**
- [x] Рампа — гекс нижнего уровня с высокой кромкой, по коду стенда.
- [x] 2 шага за проезд: вход и выход в одном ходу.
- [x] Стоять по своей воле нельзя; подбитый или отброшенный на ней стоит и запирает её.
- [x] Сквозь пустую рампу стреляют; танк на рампе — на нижнем уровне.
- [x] Отброшенный вдоль оси скатывается на нижний уровень.
- [x] Согласовано со стендом — таблица ниже, строки про грань и стояние сняты.

**Сверка со стендом** ([../board.md](../../godot/docs/board.md), «Ramp-граф», «Съезд»):

|---|---|---|---|

Либо правила запрещают таран вниз без рампы, либо стенд получает исключение для тарана |
| Ограничение на карту | нет | у пандуса ровно один сосед выше, два смежных пандуса непроходимы, высокая кромка смотрит в 30/90/150 из-за камеры | Это ограничения стенда на дизайн карт, не правила. В редактор карт (U-14, docs/editor.md) |

- [x] Таран сталкивает и без рампы. Правила не уступают; стенд правил не реализует (U-15), так что его `Passable` здесь не при чём.

Закрыто: 2026-09-05, полностью. GDD «Рампа», «Таран», «Препятствия → вода».

## U-05. Башня: цена и память поворота `P0`

Танки стреляют в 6 направлениях «потому что есть башня», но не сказано, стоит
ли поворот башни шаг и сохраняется ли её направление между ходами. От этого
зависит засада: она фиксирует ось «поворотом башни или корпуса».

**Из C-07 цена корпуса задана:** разворот после прибытия стоит по шагу за 60° и
идёт из того же бюджета MP, что проезд. Для TD и HM это и есть цена наведения.
Цена башни по-прежнему не задана.

**Решение (2026-09-05).** Поворот башни бесплатен, один раз за ход — при выстреле
или при переходе в засаду. Между ходами башня сохраняет направление, но при
движении танка выравнивается вперёд. Записано в «Пушка → Башня», у TD и HM
наведение корпусом названо словами.

**DoD**
- [x] Цена поворота башни: бесплатно.
- [x] Направление сохраняется между ходами, сбрасывается вперёд движением.
- [x] Один поворот за ход, в п. 5.
- [x] TD и HM: наведение корпусом за шаги, записано в их разделах.

**Следствие, подтверждённое автором:**
- [x] Направление башни между ходами влияет только на засаду. Броня от башни не зависит, ограничения на угол выстрела нет. Память башни — засада плюс картинка.

Закрыто: 2026-09-05, полностью. GDD «Стрельба → Пушка → Башня», «TD», «HM», «Режим засады».

## U-06. Засада `P0`

Юнит фиксирует ось и ждёт. Не сказано, сколько живёт, работает ли минимальная
дальность, тратит ли засада движение. В таблице длительностей («Ход и раунд»)
стоит как нерешённая.

**Из C-04 и C-07 закрыто два вопроса:** неразрушенная стена обрезает ось;
засада, не подбившая танк, не обрывает его путь.

**Решение (2026-09-05).** Засада — действие п. 5, одно из трёх. Двигаться перед
ней можно. Ось обрезают все препятствия линии видимости, дым укорачивает, а не
снимает. Минимальная дальность действует. Стреляет по первому вошедшему на ось,
отброшенный тараном тоже считается. По своим не стреляет. Длится до другого
приказа, уничтожения или тарана — пас и раунды её не снимают.

- [x] Стена обрезает ось (C-04).
- [x] Ось обрезают все препятствия линии видимости и юниты, в том числе свои.
- [x] Один пустой гекс до цели действует: соседний гекс оси не стреляется.
- [x] По первому пересёкшему.
- [x] Дым не снимает засаду, укорачивает ось.
- [x] Засада в п. 5 наравне с выстрелом и способностями.
- [x] Двигаться перед засадой можно.
- [x] Отброшенный тараном через ось — пересечение, засада стреляет.
- [x] По своим не стреляет.

**Следствия, закрытые автором (2026-09-05):**
- [x] Засада тратится выстрелом: один приказ — один выстрел.
- [x] Любое действие засадного снимает засаду, тушение тоже. Загоревшийся засадный, спасаясь, засаду теряет — осознанная цена.
- [x] Ось перепроверяется при срабатывании: препятствия появляются и исчезают.

Закрыто: 2026-09-05, полностью. GDD «Режим засады», «Ход и раунд», «Структура хода» п. 5.

таблицей для корпуса на N.

## U-08. Подбитый танк и его взрыв `P1`

«Выстрел по подбитому → взрывается, поражая соседние гексы». Не сказано, что
значит «поражает» и учитывается ли броня при выстреле в подбитого.

**Из C-03 и C-04:** утопленный взрывается как подбитый; взрыв сносит все стены

стреляет по осям без других лесных гексов; танк в глубине прикрыт соседями, а не
своим гексом. Правило симметрично. Записано в field.md «Уровни и линия огня» и у
деревьев, ссылка в units.md «Цель выстрела».

**Вместе с этим (2026-09-05):** лес перестал гореть от обычного выстрела. Поджигают
его взрыв, зажигательный снаряд (апгрейд) и распространение. Зажигательный
принят в upgrades.md, он же поджигает непробитый танк.
