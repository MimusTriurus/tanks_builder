# Классы

Часть правил [Board of Tanks](index.md). Соседние части: [поле](field.md), [классы](classes.md), [юниты](units.md), [апгрейды](upgrades.md), [состояния](states.md), [партия](match.md), [режимы](GameModes.md). Открытые вопросы — [contradictions.md](contradictions.md), [undefined.md](undefined.md).

Пять классов и чем они различаются. У каждого класса свой файл в
[units/](units/): роль, числа, кого он берёт и кто берёт его, особенность,
слабости, стартовый апгрейд и дерево прокачки. Правила, общие для всех, —
движение, стрельба, засада, таран, апгрейды, зоны брони — в [units.md](units.md).

## Пять классов

| | [LT](units/lt.md) | [MT](units/mt.md) | [HT](units/ht.md) | [TD](units/td.md) | [HM](units/hm.md) |
|---|---|---|---|---|---|
| **Класс** | лёгкий танк (Light Tank) | средний танк (Medium Tank) | тяжёлый танк (Heavy Tank) | истребитель танков, ПТ-САУ (Tank Destroyer) | тяжёлый миномёт (Heavy Mortar) |
| **Роль** | охотник за бортами и кормой, разведка | середина во всём, часовой | якорь, осада | огневая мощь через препятствие | артиллерия поверх всего |
| **Скорость, шагов** | 5 | 4 | 3 | 4 | 3 |
| **Огневая мощь** | I | II | III | IV | V |
| **Броня лоб / борт / корма / крыша** | I / 0 / 0 / 0 | II / I / 0 / I | III / II / I / II | II / I / 0 / 0 | I / 0 / 0 / 0 |
| **Масса** | I | II | III | II | I |
| **Башня** | есть | есть | есть | нет, наводка корпусом за шаги | нет, наводка корпусом за шаги |
| **Особенность** | [свободный порядок](units/lt.md): атака и дополнительное действие — каждое до движения или после | [секторная засада](units/mt.md): две соседние оси, по выстрелу на каждую | [бульдозер](units/ht.md): таран сквозь стены и с ходу, посреди пути, стену проезжает за шаг, лес под остановкой падает | [тяжёлый снаряд](units/td.md): пробивает первое на оси (танк или стену) и летит дальше с мощью −1 | [навес](units/hm.md): бьёт по гексу на 3–5 клетки поверх всего, всегда в крышу |
| **Измерение особенности** | порядок («до») | ожидание («две оси») | карта («убирает» укрытия и танки с пути) | проход («через») | навес («поверх») |
| **Кого берёт в лоб на своём уровне** | никого | LT, HM | LT, HM, MT, TD | всех | всех |
| **Слабость / цена** | в лоб не пробивает никого; стреляет с позиции, которую противник видел | особенность работает, только пока караулит | 3 шага, медленно доезжает | крыша 0, наводка корпусом стоит шагов | борта 0, гибнет от любого попадания не в лоб; мёртвая зона 1–2 клетки |
| **Контригра** | не подставлять борт; засада на оси, куда он уйдёт после выстрела | четыре свободные оси, дым на одну из двух, таран снимает засаду, HM | мины и пожар на подходе, HM, не дать доехать | лес (проходом не бывает; против «Сквозь лес» — два гекса), обход с борта, заход сверху | подойти вплотную, удар в борт |

Особенности — свойства класса, не апгрейды; апгрейды их усиливают или дают
чужое. Пять особенностей, каждая в своём измерении: **TD** стреляет **через**
стену или танк (проход), **HM** стреляет **поверх** всего (навес), **HT** укрытие
**убирает** (карта), **LT** действует **до** движения (порядок), **MT** караулит
**две оси** (ожидание).

В грязи и лесу классы нарочно не различаются: одна клетка уравнивает всех.

## Сравнение классов

То, что читается только парой классов, а не одним.

**Крыша — не четвёртая грань, а уровень:** её читает любой выстрел с уровня выше
(см. units.md "Броня"). Значения не задаются списком, а выводятся из башни:
**у башенного танка крыша равна борту, у казематного — корме.** Башня и есть
крыша; над рубкой TD и HM её нет. Тот же признак делит классы в контракте
`Sprites/` — у LT, MT и HT есть слой башни, у TD и HM его не бывает.

Что высота вскрывает, а что нет:

| Стрелок | берёт в лоб на своём уровне | берёт сверху, в крышу |
|---|---|---|
| LT (I) | никого | LT, TD, HM |
| MT (II) | LT, HM | + MT, TD |
| HT (III) | LT, HM, MT, TD | + HT |
| TD (IV) | всех | всех |
| HM (V) | всех | всех |

Смысл столбца — **вскрыть зеркало**: равный класс в лоб непробиваем, и до крыши
единственным ключом к нему был обход с борта. Теперь ключей два, и оба стоят
шагов и открытой позиции. HT при этом остаётся якорем: сверху его берут ровно
те, кто брал его и внизу, плюс он сам. HM остаётся собой: крыша требует занять
высоту, выйти на кромку и иметь линию огня, а мина не требует ничего.

Сдвинуть можно только танк не тяжелее себя: таран возможен, если масса
таранящего **не меньше** массы цели. Масса идёт по корпусу: TD на среднем, HM на
лёгком. Правило «не меньше» даёт равным классам таран друг против друга.

| Таранит → цель | LT | MT | HT | TD | HM |
|---|---|---|---|---|---|
| LT (I) | да | нет | нет | нет | да |
| MT (II) | да | да | нет | да | да |
| HT (III) | да | да | да | да | да |
| TD (II) | да | да | нет | да | да |
| HM (I) | да | нет | нет | нет | да |
