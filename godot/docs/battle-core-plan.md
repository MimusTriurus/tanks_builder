# Доработки перед ИИ: ядро правил партии и пробелы

Цель — довести партию до состояния, на котором можно писать ИИ противника
([ai-plan.md](ai-plan.md)). Для ИИ нужно три вещи, и сейчас нет ни одной:

1. **Правила партии как данные.** Состояние, которое можно копировать и
   применять к нему приказы тысячи раз за ход, без сцены и физики.
2. **Один исход.** Что посчитало ядро, то и показывает стенд, и оба совпадают
   с GDD.
3. **Приказ без мыши.** Любое действие игрока доступно командой с теми же
   проверками.

Документ составлен 2026-10-30 по коду `main` (`1f20ee1d`) и GDD
(`docs/gdd/*.md`). Ссылки — `scripts/…:строка` на эту дату. Обзор того, что есть,
— в [ai-plan.md](ai-plan.md), «Как сейчас в коде».

## Решения (приняты автором 2026-10-31, все пять — как предложено)

| # | Вопрос | Решение |
|---|---|---|
| Р-1 | Кто решает исход в партии: ядро или стенд? | **Ядро.** Стенд проигрывает события ядра. Переход идёт по механике за раз, через теневой режим (Д3, Д4). Иначе П-4 не закрыть никогда. |
| Р-2 | Лес и линия огня (П-9) | Как в GDD: лес закрывает. Правка `terrain.json` вместе с `Terrain.cs` (они должны совпадать). Проверить карты, где лес стоит между спавнами. |
| Р-3 | Порядок механик В | Пат и тик поля → засада → дым → апгрейды стартового отряда → расстановка → точка. |
| Р-4 | Где задаются апгрейды до меты | В спавне карты (`Parking`), как класс. Без записи — стаб из match.md: LT ОПВТ, MT трал, HM шашка. |
| Р-5 | Контрольная точка в редакторе | Отдельная вкладка или кисть на вкладке Cover, гекс или гекс с шестью соседями, N — свойство карты. |

## Этапы

Этапы идут по зависимостям. **ИИ можно начинать после Д5**: к этому времени ядро
знает всё, что умеет стенд, и стенд с ядром согласны. Недостающие механики
(Д6–Д9) дальше входят по одной сразу в три места: ядро, стенд и ИИ.

```
Д1 ─► Д2 ─► Д3 ─► Д4 ─► Д5 ═══► ИИ (И1…)
                 │            ▲
                 └► Д6 ─► Д7 ─► Д8 ─► Д9   (по механике, параллельно с ИИ)
                                       Д10 — после Д3, когда понадобится самоигра
```

## Как проверять

  команд не добавляют выделений в кадр; ядро выделяет только на ходе.
