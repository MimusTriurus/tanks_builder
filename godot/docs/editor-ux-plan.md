# План доработки редактора карт: удобство автора

Цель: автор рисует карту, проверяет её в игре и возвращается править за секунды
и без потерь, а инструменты редактора совпадают с тем, чего он ждёт от любого
редактора карт. Правила, формат и облик доски не меняются: это план про то,
**как с редактором работать**. Про то, **что** редактор рисует (3D-облик, рельеф,
вкладка Units), — [editor3d-plan.md](editor3d-plan.md) и [editor.md](editor.md).

Составлен 2026-10-26 по коду, документации, снимкам и ошибкам, найденным в тот
день; в самом редакторе руками не рисовали. Первым делом стоит проверить его на
живом авторе (этап 0, «Проверка»).

## Как сейчас

**Опора крепкая:**
- доска выглядит как в игре: рельеф, кольцо моря, вода, лес, трава, танки на спавнах;
- правила (`MapRules`) судят карту на лету, достижимость считается с каждого спавна;
- отмена и повтор по мазку, заливка, пипетка, радиус кисти, слои;
- формат `maps/*.json` читаемый и проверяется обратным чтением при сохранении;
- переход к игре и обратно идёт под заставкой с полосой ([architecture.md](architecture.md), `Loading`).

**Что мешает работать:**

1. **Тест-драйв дорогой.** Run (F5) сохраняет карту на диск, выгружает редактор и
   строит стенд; `Edit` строит редактор заново (`Session`, `MapEditor.Play`,
   `Tank3DBench.Edit`). Из этого:
   - попробовать без перезаписи файла нельзя;
   - на вшитой карте Run упирается в «Not saved»;
   - история отмены пропадает при каждом запуске;
   - круг «поправил → сыграл → вернулся» стоит около 7 с на `drill10`.
2. **Отчёт лежит на доске.** `_report` (`MapEditor.Report`) — 520 × 420 px текста
   над левым верхним углом карты: строки достижимости и ошибок закрывают клетки.
3. **Вкладки следуют модели, а не задаче.** Foundation / Cover / Level / Units —
   оси клетки. Пруд — это уровень на одной вкладке и вода на другой; холм с лесом
   — три прохода.
4. **Нет базовых инструментов:**
   - выделения области, копирования, вставки, переноса куска;
   - симметрии — для карты двух сторон это главный инструмент;
   - изменения размера и сдвига доски («нет в скелете», [editor.md](editor.md));
   - списка недавних карт и автосохранения: автосохранение сознательно не
     делали, потому что недописанная карта в `maps/` ломает чтение сцен
     (`MapEditor.Guarded`).
5. **Сообщения написаны для разработчика.**
   - Пример: «bench is a board this build already writes, and two references
     under one name is what the self test judges…».
   - `--map` с неизвестным именем молча открывает `bench` (`BoardMap.ByName`).
   - Редактор на английском, HUD партии на русском.
6. **Клавиши свои, а не общепринятые.**
   - Сохранение — `S`, отмена — `Z`, повтор — `Y`; `Q`/`W`/`E` — смена кисти и
     переключатели.
   - Одиночных букв почти не осталось, а `Ctrl+S`, `Ctrl+Z`, `Ctrl+Shift+Z`
     автор нажмёт первыми.

## Что берём из устоявшихся редакторов

Ориентиры: Tiled, LDtk, редакторы уровней Unity и Unreal, World Editor
Warcraft III и ближе всего к нам — гексовый редактор карт Battle for Wesnoth.

| паттерн | суть | у нас |
|---|---|---|
| Play-in-Editor | игра запускается из того, что в памяти, без сохранения, часто с точки под курсором; выход возвращает ровно туда же, с историей | через диск, редактор пересобирается |
| инструменты / палитра / инспектор | слева инструменты (кисть, линия, прямоугольник, заливка, выделение, пипетка), рядом палитра «чем», справа свойства выбранного | вкладки смешивают палитру и инструменты; инструменты — клавишами |
| панель проблем | ошибки списком, щелчок переносит к клетке, на доске только значок | текст поверх доски |
| пресеты и штампы | одна кисть ставит несколько осей сразу; кусок карты сохраняется штампом | нет |
| симметрия | кисть отражается на вторую половину | нет |
| свойства документа | имя, размер, сдвиг, недавние, автосохранение в сторону | имя и размер в диалоге «Новая» |
| стандартные клавиши | `Ctrl+S/Z/Shift+Z/C/V/X/D`, `B`/`G`/`I` — кисть, заливка, пипетка | свои одиночные буквы |

## Этапы

Порядок — по выигрышу на единицу работы. Этап 1 самый ценный и самый крупный;
этап 0 дешёвый и снимает раздражители, его можно делать первым или параллельно.
Размер: S — до дня, M — пара дней, L — неделя.

### Этап 0 — быстрые правки (S)

**Сделано 2026-10-26**, кроме проверки живым автором: панель проблем, сообщения,
`Ctrl`-сочетания — [editor.md](editor.md), «Панель проблем, сообщения, клавиши».
Проверено снимками: `drill10` с доской без текста, щелчок по строке
(`--menu problem`, на повороте тоже), `--map events`, Run на `abbey`. Красные
строки на снимке не видели: открытые карты все без роковых ошибок.

- **Панель проблем вместо текста на доске.**
  - `_report` уходит в сворачиваемую панель (справа под панелью клетки или снизу)
    со списком ошибок; на доске остаются значки `Fault` у клеток.
  - Щелчок по строке переносит камеру к клетке и выбирает её.
  - Роковые и нероковые ошибки различаются цветом и иконкой.
  - Достижимость — одна строка-сводка («со всех 10 спавнов доступно 100 клеток»),
    подробности по раскрытию.
- **Понятные сообщения.**
  - Отказ сохранения: «Это встроенная карта — сохраните её под другим именем»,
    с кнопкой «Сохранить как…» в том же окне.
  - Неизвестная карта в `--map`: сказать об этом в строке состояния и открыть
    пустую доску, а не `bench`.
- **Стандартные клавиши в добавок к нынешним:** `Ctrl+S`, `Ctrl+Shift+S`,
  `Ctrl+Z`, `Ctrl+Shift+Z` / `Ctrl+Y`, `Ctrl+O`, `Ctrl+N`. Одиночные буквы
  остаются, пока не решено иначе (вопрос 3).
- **Проверка** (до всего остального): полчаса рисования карты с нуля живым
  автором, с записью, где он споткнулся. Результат может переставить этапы ниже.

**Готово, когда:** на снимке `--capture` доска свободна от текста; щелчок по
ошибке в панели выбирает её клетку; `Ctrl+Z` отменяет; Run на вшитой карте
предлагает «Сохранить как…».

### Этап 1 — Play-in-Editor (L)

Запуск игры из памяти, без записи на диск, и возврат без пересборки редактора.

**Сделано 2026-10-26** — [editor.md](editor.md), «Play-in-Editor». Отличия от
плана: отложенный редактор не держит меши через «удаление вместо выхода», а
пропускает сброс на `_ExitTree`, пока `Loading.Parking`; «Сыграть отсюда» не
поворачивает танк к центру — он стоит, как стенд ставит по умолчанию; в партии
старт с клетки не делался. Возврат 40–80 мс; файл на диске не меняется.

1. **Карта передаётся объектом, а не именем.**
   - `Session` получает `BoardMap? Board` — собранную из `MapEdit` карту.
   - `Tank3DBench.TakeSession` берёт её вместо `BoardMap.ByName`.
   - Run больше не сохраняет; «Сохранить» — отдельное решение автора.
   - Вшитая карта играется без отказа.
2. **Редактор не выгружается, а откладывается.**
   - Вместо `ChangeSceneToFile("res://Editor.tscn")` узел редактора снимается с
     дерева (`RemoveChild`), но не освобождается; ссылка на него лежит в `Session`.
   - Стенд добавляется рядом. `Edit` освобождает стенд и возвращает тот же
     экземпляр редактора: undo, камера, вкладка, кисть, выбранная клетка — всё на месте.
   - Возврат — мгновенный: 2 с пересборки уходят.
   - Риски:
     - снятый с дерева узел не получает `_Process`, но держит ресурсы: память ×2
       на время игры;
     - всё, что редактор повесил на корень (`Loading`, диалоги), — проверить;
     - камера и `Environment` редактора не должны остаться текущими.
3. **«Сыграть отсюда».**
   - `Shift+F5` ставит танк игрока на клетку под курсором, лицом к центру доски
     (у стенда уже есть `--cell` / `_startCell`).
   - В партии (`Ctrl+F5`) — ход стороны, чей спавн ближе.
4. **Грязная карта видна в игре.** HUD стенда пишет «несохранённая карта», а
   `Edit` возвращает к той же грязной карте, а не к файлу.

**Готово, когда:**
- Run → Edit на `drill10` с несохранённой правкой возвращает правку и её отмену;
- файл на диске не тронут (`git status` чист);
- возврат занимает меньше 0,5 с;
- вшитая `abbey` играется по F5;
- `--edit-at` и `--menu run` / `runmatch` проходят круг без ошибок.

### Этап 2 — выделение, буфер, перенос (M)

**Сделано 2026-10-26** — [editor.md](editor.md), «Выделение, буфер, перенос,
штампы». Чётность решена через осевые координаты (`MapEdit.Shift`), а не
округлением сдвига. Отличия от плана: инструмент выделения — `R`, а не `M`
(`M` — трава); штампы не в палитре вкладки, а в Edit → Stamps; спавны при
вставке едут всегда, без танков — `Ctrl+Shift+V`. Проверено пробами `clip` и
`cliptanks` и снимком; руками мышью — нет.

- Инструмент «выделение»: прямоугольник по гексам (odd-q), `Shift` — добавить,
  `Alt` — убрать. Выделение видно контуром на доске.
- `Ctrl+C` / `Ctrl+X` / `Ctrl+V`: буфер — кусок `MapEdit` по всем осям
  (пол, покрытие, уровень, вода, стены, спавны по выбору). Вставка — призраком
  под курсором, щелчок кладёт.
- Перенос выделения перетаскиванием. Одна отмена на операцию.
- **Чётность столбца:** у odd-q нечётные столбцы сдвинуты на полряда. Кусок,
  перенесённый на нечётное число столбцов, меняет соседство — так же, как кольцо
  моря (`BoardMap.Moated`). Вставка либо округляет сдвиг до чётного, либо
  пересчитывает через кубические координаты; решить на этапе.
- Штампы: выделение сохраняется в `maps/stamps/*.json` (папка, которую сцены не
  читают) и появляется в палитре.

**Готово, когда:** кусок `abbey` с рекой копируется в пустую доску и встаёт без
ошибок `MapRules`, а отмена снимает вставку целиком.

### Этап 3 — симметрия (M)

**Сделано 2026-10-26** — [editor.md](editor.md), «Симметричная кисть». Отличия от
плана: формула ниже про W−1 перевёрнута — точная пол-оборота у **чётной**
ширины (центр на ребре), у нечётной без близнеца остаются по клетке нечётных
столбцов; режим по умолчанию не «для двух сторон», а тот, что доска уже держит
(пустая — пол-оборота, вопрос 4 остаётся); клавиша `P`; перетаскивание и
поворот танка мышью не отражаются. Проверено пробой `sym` и снимком; руками
мышью — нет.

- Режимы кисти: нет / точечная (поворот на 180° вокруг центра доски) /
  зеркальная по вертикали / по горизонтали. Переключатель на панели, клавиша.
- Для двух сторон по умолчанию — точечная: зелёный спавн рождает коричневый на
  отражённой клетке, с повёрнутым направлением.
- **Гексы:** точечная симметрия (q, r) → (W−1−q, H−1−r) сохраняет соседство,
  только если W−1 чётно, иначе чётность столбцов меняется. Зеркала у
  плоскотоповой сетки неравноправны: одно точное, другое — со сдвигом на полряда.
  Расчёт — через кубические координаты; размеры, на которых точная симметрия
  невозможна, панель называет.
- Аудит: нероковая проверка «карта несимметрична в N клетках» для двухсторонних
  карт — вывод, а не правило.

**Готово, когда:** карта 11 × 10, нарисованная с точечной симметрией, проходит
проверку «несимметрично в 0 клетках», а спавны сторон отражены друг в друга.

### Этап 4 — документ и сервис (S–M)

**Сделано 2026-10-26** — [editor.md](editor.md), «Доска как документ». Отличия от
плана: панель «Карта» — окно File → Board…, а не постоянная панель; при
открытии предлагается и автосохранение карты без файла (встроенной или
`untitled`). По дороге найден и исправлен ложный водопад при смене размера с водой
на доске (порядок слоёв в `Settle`, защита по длине в `HexField.Drafted`).
Проверено пробами `board` и `quit`, снимками и кругом Run → Edit; руками
мышью — нет.

- Панель «Карта»: имя, размер, **изменение размера с выбором угла привязки**,
  сдвиг на чётное число столбцов, обрезка по выделению.
- File → Недавние (5 последних, в `user://`).
- Автосохранение **в сторону**: раз в минуту и перед Run — в
  `user://autosave/<имя>.json`, не в `maps/`; при открытии предлагается, если
  оно новее файла. Довод `MapEditor.Guarded` (недописанная карта в `maps/`
  ломает сцены) этим не нарушается.
- Предупреждение при закрытии окна с несохранённой картой.

### Этап 5 — кисти-пресеты и панель инструментов (M)

- Пресеты поверх вкладок, не вместо них:
  - «пруд» — уровень −1 и глубокая вода;
  - «брод» — вода у края водоёма;
  - «холм» — уровень +1 с плавным краем радиуса;
  - «лес на холме», «болото» — грязь с водой.
  
  Пресет — запись в данных (`editor_presets.json`), а не код, чтобы добавлять
  без сборки.
- Полоса инструментов: кисть / линия / прямоугольник / заливка / выделение /
  пипетка, с клавишами `B`, `L`, `U`, `G`, `M`, `I` там, где они свободны
  (вопрос 3). Вкладки остаются палитрой «чем».
- Призрак кисти показывает результат пресета до щелчка (сейчас — только
  контур, [editor.md](editor.md), «призрак кисти»).

3. **Клавиши:** переводить одиночные буквы на стандартную раскладку

4. **Симметрия по умолчанию** для новой двухсторонней доски — точечная или
   зеркальная?

## Как проверять

Как всё в редакторе, глазами и флагами снимка ([editor.md](editor.md),
«Что судится глазами»):
- `--menu`, `--pick`, `--hover`, `--tab` и `--capture` для каждого нового
  инструмента;
- круг Run → Edit — `--menu run --edit-at 30`;
- строка `load:` в логе — время возврата.

Самотест редактор не создаёт; правила карты (`MapRules`) он судит, и этапы 2–3,
трогающие `MapEdit`, проверяются им — по просьбе.
